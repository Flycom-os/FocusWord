Документация по модулям админ-панели

В этом документе представлено подробное описание каждого модуля, доступного в административной панели. Каждый раздел объясняет назначение модуля, его основные функции и возможности.

Аналитика (Analytics)

URL: /admin/analytics | Ресурс: media-files | Мин. уровень: 0

Модуль "Аналитика" является центральным хабом для отслеживания ключевых показателей эффективности (KPI) вашего проекта. Он предоставляет администраторам и менеджерам исчерпывающую картину активности пользователей, популярности контента и коммерческих успехов. Основная задача этого раздела — преобразование сырых данных в наглядные и понятные отчеты, которые помогают принимать обоснованные бизнес-решения. На главной странице модуля обычно располагается дашборд с ключевыми метриками: количество уникальных посетителей, общее число просмотров страниц, источники трафика, показатели отказов и среднее время, проведенное на сайте. Эти данные могут быть представлены в виде интерактивных графиков и диаграмм, позволяющих отслеживать динамику за различные периоды времени (день, неделя, месяц, год).

Кроме общих данных о трафике, модуль аналитики предоставляет глубокий анализ поведения пользователей. Вы можете увидеть, какие страницы, статьи или товары являются наиболее популярными, как пользователи перемещаются по сайту, и на каких этапах они чаще всего покидают его. Для e-commerce проектов здесь отображается информация о продажах: количество заказов, средний чек, коэффициент конверсии и общий доход. Особое внимание уделяется воронкам продаж, что позволяет выявлять узкие места в процессе оформления заказа. Модуль также может включать в себя функционал для A/B тестирования, позволяя сравнивать эффективность различных версий страниц. Гибкая система фильтрации и сегментации аудитории (по географии, устройству, поведению) дает возможность проводить детальный анализ конкретных групп пользователей. Интеграция со сторонними сервисами, такими как Google Analytics или Яндекс.Метрика, значительно расширяет его возможности, объединяя все данные в едином интерфейсе.

Продукты (Products)

URL: /admin/products | Ресурс: media-files | Мин. уровень: 0

Модуль "Продукты" — это ядро управления каталогом товаров в любом проекте электронной коммерции. Он предоставляет полный набор инструментов для создания, редактирования, организации и удаления товарных позиций. Через этот интерфейс менеджеры могут легко управлять всеми аспектами продуктовой базы. При добавлении нового товара открывается форма с множеством полей: название, подробное описание с использованием WYSIWYG-редактора, артикул (SKU) для уникальной идентификации, цена, а также опциональная цена со скидкой. Важной частью является управление медиа-контентом: можно загружать несколько изображений для каждого товара, задавать их порядок и выбирать главное изображение.

Система управления продуктами поддерживает сложные товарные структуры, такие как вариативные товары. Например, для одежды можно создать варианты по цвету и размеру, причем для каждой вариации можно указать собственную цену, артикул и количество на складе. Это устраняет необходимость создавать отдельные карточки для каждого варианта. Продукты можно организовывать, przypisując im одну или несколько категорий, что облегчает навигацию для покупателей. Также присутствует функционал для управления остатками: можно указать количество товара на складе, включить или отключить автоматическое списание при заказе и настроить уведомления о низком остатке. Дополнительные возможности включают управление сопутствующими и рекомендуемыми товарами, настройку SEO-атрибутов (мета-заголовки, описания) для каждой товарной страницы и управление статусом товара (опубликован, черновик, архив).

Категории продуктов (Categories)

URL: /admin/product-categories | Ресурс: media-files | Мин. уровень: 0

Модуль "Категории продуктов" предназначен для структурирования товарного каталога и создания логичной иерархии, которая помогает пользователям легко находить нужные товары. Эффективная организация категорий напрямую влияет на юзабилити сайта и, как следствие, на конверсию. Этот модуль позволяет создавать, редактировать и удалять категории товаров, а также управлять их вложенностью. Вы можете создавать родительские категории (например, "Электроника") и вложенные в них дочерние категории (например, "Смартфоны", "Ноутбуки"), формируя многоуровневое дерево каталога. Такой подход обеспечивает масштабируемость и гибкость при росте ассортимента.

Для каждой категории можно задать не только название, но и ряд дополнительных атрибутов. Важнейшими из них являются SEO-параметры: уникальный URL (слаг), мета-заголовок и мета-описание. Грамотное заполнение этих полей существенно улучшает видимость категорий в поисковых системах. Также можно добавить уникальное описание для каждой категории, которое будет отображаться на ее странице, и загрузить изображение или иконку для визуального представления. Интерфейс модуля часто поддерживает drag-and-drop для легкого изменения порядка сортировки категорий и их иерархии. Кроме того, к категориям могут быть привязаны специфические фильтры и характеристики товаров, что позволяет реализовать фасетный поиск (например, фильтрация ноутбуков по диагонали экрана или объему оперативной памяти).

Обратная связь (Feedback)

URL: /admin/feedback | Ресурс: media-files | Мин. уровень: 0

Модуль "Обратная связь" служит централизованным местом для сбора и обработки всех сообщений, отправленных пользователями через различные формы на сайте, будь то контактная форма, форма заказа обратного звонка или виджет для предложений. Основная цель модуля — обеспечить своевременную реакцию на запросы клиентов и не упустить ни одного обращения. Все поступающие сообщения отображаются в виде списка, который можно сортировать и фильтровать по различным критериям, таким как дата получения, статус (новое, прочитанное, в работе, заархивированное) или тема обращения. Для каждого сообщения отображается основная информация: имя отправителя, его контактные данные (email или телефон) и текст самого сообщения.

Эффективная работа с обращениями обеспечивается системой статусов. Новое сообщение автоматически получает статус "Новое", который меняется после того, как менеджер открывает его. Это позволяет легко отслеживать необработанные запросы. Продвинутые версии этого модуля могут включать возможность прямого ответа на сообщение из админ-панели, при этом переписка с клиентом будет сохраняться в виде единой цепочки. Также могут быть реализованы функции назначения ответственного менеджера за конкретное обращение и добавления внутренних комментариев, видимых только сотрудникам. Для борьбы со спамом модуль часто интегрируется с системами защиты, такими как Google reCAPTCHA, и позволяет вручную помечать сообщения как спам.

Медиафайлы (Media files)

URL: /admin/media-files

Модуль "Медиафайлы" — это файловый менеджер и центральное хранилище для всех медиа-ресурсов, используемых на сайте. Он позволяет управлять изображениями, видео, документами (PDF, DOCX) и другими файлами, которые загружаются администраторами и редакторами. Вместо того чтобы загружать один и тот же файл несколько раз для разных страниц или товаров, можно загрузить его один раз в медиатеку и затем повторно использовать в любом месте сайта. Это не только экономит дисковое пространство, но и значительно упрощает управление файлами. Все загруженные файлы представлены в виде сетки или списка с миниатюрами для удобного визуального поиска.

Функционал модуля включает в себя загрузку файлов (часто с поддержкой drag-and-drop и мультизагрузки), их удаление и переименование. Для изображений могут быть доступны базовые инструменты редактирования, такие как обрезка (кроп), поворот и изменение размера. Важной функцией является возможность задавать метаданные для каждого файла, в частности, атрибуты `alt` (альтернативный текст) и `title` (заголовок) для изображений, что крайне важно для SEO и доступности сайта для людей с ограниченными возможностями. Также модуль позволяет организовывать файлы по папкам, создавая логическую структуру хранилища (например, "Товары", "Статьи блога", "Баннеры"). Поиск и фильтрация по названию, дате загрузки или типу файла помогают быстро находить нужные ресурсы.

Слайдеры (Sliders)

URL: /admin/sliders | Ресурс: sliders | Мин. уровень: 0

Модуль "Слайдеры" предоставляет интуитивно понятный интерфейс для управления динамическими баннерами и каруселями на главных и других страницах сайта. Слайдеры являются важным элементом дизайна, позволяющим эффектно презентовать акции, новые продукты или ключевые сообщения. Этот модуль дает возможность создавать неограниченное количество слайдеров, каждый из которых может быть размещен в определенной части сайта. Например, можно создать один слайдер для главной страницы, а другой — для страницы акций.

Для каждого созданного слайдера можно добавлять, редактировать и удалять отдельные слайды. Управление слайдами очень гибкое: для каждого из них можно загрузить фоновое изображение (отдельно для десктопной и мобильной версий), добавить текстовый контент (заголовок, подзаголовок), а также кнопку с призывом к действию (CTA), ведущую на определенную страницу. Интерфейс обычно поддерживает технологию drag-and-drop, что позволяет легко менять порядок слайдов. Кроме того, в настройках самого слайдера можно задавать такие параметры, как скорость автоматической прокрутки, наличие стрелок навигации и точек-индикаторов, а также тип анимации перехода между слайдами. Это позволяет полностью кастомизировать внешний вид и поведение карусели без необходимости вмешиваться в код.

Записи (Records)

URL: /admin/records | Ресурс: records | Мин. уровень: 0

Модуль "Записи" представляет собой гибкий и универсальный инструмент для создания и управления пользовательскими типами контента. Если стандартных модулей, таких как "Статьи" или "Товары", недостаточно для реализации специфических задач проекта, на помощь приходят "Записи". Этот модуль может быть использован для чего угодно: портфолио работ, кейсы, отзывы клиентов, список вакансий, каталог объектов недвижимости и многое другое. Главная особенность этого модуля — его абстрактность и возможность кастомизации под конкретные нужды. Администратор может определить набор полей, которые будут у каждой "записи", что делает его невероятно мощным инструментом.

В рамках модуля можно создавать новые записи, используя предопределенную структуру. Например, если модуль настроен для портфолио, каждая запись может содержать поля для названия проекта, описания, даты выполнения, списка использованных технологий и галереи изображений. Записи можно группировать по категориям (управляемым в соседнем модуле "Категории записей"), что обеспечивает удобную навигацию и фильтрацию. Как и другие контентные модули, "Записи" поддерживают управление статусами (черновик, опубликовано), настройку SEO-параметров для каждой отдельной записи и возможность прикрепления медиафайлов. Благодаря своей гибкости, этот модуль позволяет расширять функционал сайта без привлечения разработчиков для создания новых разделов с нуля.

Категории записей (Category)

URL: /admin/records/categories | Ресурс: record-categories | Мин. уровень: 0

Модуль "Категории записей" является дополнением к модулю "Записи" и выполняет ту же функцию, что и категории для товаров или статей: он позволяет структурировать и организовывать пользовательский контент. Если модуль "Записи" используется для создания портфолио, то категории могут быть, например, "Веб-дизайн", "Мобильные приложения", "Брендинг". Если же это каталог рецептов, то категориями могут стать "Супы", "Десерты", "Напитки". Этот модуль позволяет создавать иерархическую структуру, где у каждой категории может быть родительская, что обеспечивает возможность создания сложных и логичных классификаций.

Для каждой категории можно задать имя, уникальный URL-адрес (слаг) для формирования красивых ссылок, а также описание. Как и в других модулях категоризации, здесь крайне важна возможность настройки SEO-атрибутов (мета-заголовок и мета-описание) для страниц категорий, что помогает в их продвижении в поисковых системах. Простой и понятный интерфейс позволяет легко добавлять новые категории, редактировать существующие и управлять их порядком и вложенностью, часто с помощью перетаскивания (drag-and-drop). Наличие этого модуля превращает абстрактный набор "записей" в полноценный, хорошо структурированный раздел сайта, удобный как для администраторов, так и для конечных пользователей.

Страницы (Pages)

URL: /admin/pages | Ресурс: pages | Мин. уровень: 0

Модуль "Страницы" предназначен для управления статическим контентом сайта. Это страницы, которые не являются частью блога, каталога товаров или другого динамического раздела. Типичные примеры таких страниц — "О нас", "Контакты", "Условия использования", "Политика конфиденциальности", "Доставка и оплата". Этот модуль предоставляет полный контроль над содержимым таких страниц, позволяя создавать, редактировать и удалять их без каких-либо знаний в области программирования.

Центральным элементом при редактировании страницы является WYSIWYG-редактор (What You See Is What You Get), который позволяет форматировать текст, вставлять изображения и видео, создавать таблицы и ссылки, работая в визуальном режиме, похожем на обычный текстовый редактор. Для каждой страницы можно задать уникальный URL (слаг), что важно для создания понятной структуры сайта и для SEO. Модуль также включает обязательные поля для SEO-оптимизации: мета-заголовок, мета-описание и ключевые слова. Продвинутые системы могут поддерживать разные шаблоны страниц (например, страница с боковой колонкой или без нее), а также возможность включать и отключать отдельные блоки на странице. Управление иерархией страниц (создание дочерних страниц) также является стандартной функцией, позволяя, например, создать раздел "О нас" с подразделами "Наша команда" и "Наша история".

Статьи (Articles)

URL: /admin/articles | Ресурс: articles | Мин. уровень: 0

Модуль "Статьи" является основным инструментом для ведения контент-маркетинга: публикации новостей, ведения блога, создания базы знаний или любого другого раздела с регулярно обновляемыми материалами. Этот модуль предоставляет редакторам и авторам удобную среду для создания и публикации качественного контента. Процесс создания статьи похож на работу в модуле "Страницы": в основе лежит мощный WYSIWYG-редактор для форматирования текста, добавления медиафайлов и другого контента.

Однако, в отличие от статичных страниц, модуль "Статьи" обладает рядом специфических функций. Каждую статью можно przypisać к одной или нескольким категориям (управляемым в модуле "Blog" или аналогичном), а также добавить к ней метки (теги) для более точной классификации. Важной функцией является управление авторами: можно указать автора статьи из списка зарегистрированных пользователей. Также присутствует возможность задать "главное изображение" (featured image), которое будет использоваться в качестве миниатюры в списках статей и при расшаривании в социальных сетях. Для каждой статьи можно настроить SEO-параметры и задать ей кастомный URL. Одной из ключевых особенностей является возможность отложенной публикации: можно написать статью заранее и запланировать ее автоматическую публикацию на определенную дату и время. Это позволяет выстраивать контент-план и поддерживать регулярность публикаций.

Блог (Blog)

URL: /admin/blog | Ресурс: blog | Мин. уровень: 0

Модуль "Блог" часто выступает в роли управляющего центра для всего, что связано с публикацией статей. Если модуль "Статьи" — это инструмент для создания конкретных публикаций, то "Блог" — это место, где настраивается их окружение и общая структура. В этом модуле обычно происходит управление категориями блога. Например, если компания пишет о маркетинге, IT и менеджменте, то именно здесь будут созданы эти три рубрики. Для каждой категории, как правило, можно задать название, описание и SEO-атрибуты.

Помимо управления категориями, модуль "Блог" может содержать глобальные настройки для всех публикаций. Например, здесь можно настроить формат URL-адресов для статей (например, `site.com/blog/category/post-name`), включить или отключить комментарии по умолчанию для новых публикаций, а также настроить параметры RSS-ленты. В некоторых системах этот модуль может также использоваться для управления более крупными структурными единицами, чем просто категории, например, сериями статей. Это позволяет объединять несколько публикаций, посвященных одной большой теме, в последовательный цикл, что очень удобно для читателей. Таким образом, модуль "Блог" выполняет стратегическую функцию, определяя, как контент будет организован, представлен и распространен, в то время как модуль "Статьи" отвечает за тактическое создание самого контента.

В этом модуле вы можете создавать, редактировать и удалять роли. При создании или редактировании роли открывается интерфейс, где представлен список всех возможных действий в системе (просмотр аналитики, редактирование товаров, управление пользователями и т.д.), и для каждого действия можно выставить разрешение (разрешить/запретить). Например, для роли "Модератор комментариев" вы даете доступ только к модулю "Комментарии". Такой подход значительно упрощает управление правами в больших командах. Если вам нужно изменить права для целой группы сотрудников, вы просто редактируете одну роль, и изменения автоматически применяются ко всем пользователям с этой ролью. Это исключает ошибки и обеспечивает строгий контроль над тем, кто и что может делать в админ-панели.

Структурированные данные (Structured Data)

URL: /admin/structured-data | Ресурс: media-files | Мин. уровень: 0

Модуль "Структурированные данные" является мощным инструментом для SEO-специалистов и маркетологов. Он позволяет управлять микроразметкой (structured data) на сайте. Микроразметка — это специальный формат предоставления информации поисковым системам (Google, Яндекс) о содержимом страницы, используя стандартизированный словарь, чаще всего Schema.org. Правильно настроенные структурированные данные помогают поисковикам лучше понимать контент вашего сайта и могут значительно улучшить его представление в результатах поиска за счет так называемых "расширенных сниппетов" (rich snippets). Например, для страницы товара можно показать его рейтинг, цену и наличие прямо в поисковой выдаче.

Этот модуль позволяет автоматизировать процесс создания и внедрения микроразметки в формате JSON-LD, который является предпочтительным для Google. Вместо того чтобы вручную прописывать код разметки для каждой страницы, можно создать шаблоны. Например, можно настроить шаблон для товаров, который будет автоматически подставлять название, описание, цену, изображение и рейтинг из полей карточки товара в соответствующую структуру Schema.org (тип `Product`). Аналогично можно создать шаблоны для статей (тип `Article`), рецептов (тип `Recipe`), мероприятий (тип `Event`) и т.д. Этот модуль позволяет централизованно управлять всеми правилами генерации микроразметки и легко обновлять их при изменении стандартов.

Это чрезвычайно удобный инструмент для управления контентом, который должен повторяться на многих страницах, но при этом его нужно обновлять централизованно. Классический пример — блок с информацией об акции, контактными данными или призывом к действию (call-to-action). Вы создаете этот блок один раз, а затем можете разместить его на десятках страниц. Каждый блок, по сути, является мини-страницей со своим заголовком (для идентификации в админ-панели) и контентом, который создается с помощью WYSIWYG-редактора. Этот подход не только экономит время редакторов, но и обеспечивает консистентность информации на всем сайте. Модуль "Блоки" является незаменимым помощником для эффективного управления повторяющимися элементами контента.

Он предназначен для SEO-специалистов и администраторов и помогает максимизировать видимость сайта в поисковых системах.

Одной из ключевых функций является управление шаблонами мета-тегов. Можно задать шаблон, по которому будут генерироваться мета-заголовки и описания для тех страниц, где они не указаны вручную. Например, для карточки товара шаблон может быть таким: "Купить {product_name} по цене {price} в {site_name}". Другой важной функцией является генерация и управление файлом `sitemap.xml`. Этот файл сообщает поисковым системам о всех страницах сайта, которые нужно проиндексировать, и модуль автоматически обновляет его при добавлении нового контента. Также здесь часто находится редактор файла `robots.txt`, который дает инструкции поисковым роботам о том, какие разделы сайта можно сканировать, а какие — нет. Еще одной полезной функцией является "Менеджер редиректов", который позволяет настраивать перенаправления (например, 301 редирект) со старых URL-адресов на новые, что критически важно для сохранения SEO-позиций при изменении структуры сайта.
